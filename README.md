# duas de nós

Landing page da **Duas de Nós** — bijuterias e crochê feitos à mão por mãe e filha, na Feira da Glória (Rio de Janeiro), domingos das 8h às 14h.

Site estático, sem build. Basta abrir `index.html` ou servir a pasta.

## Estrutura

```
index.html      página completa (HTML + CSS + JS inline)
assets/         imagens (logo, hero e fotos do catálogo)
```
